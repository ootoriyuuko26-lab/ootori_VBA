# Excel VBA 業務支援ツール・サンプル

## 概要
実務での利用を想定して作成した、汎用的なカレンダー生成ツールです。
※本リポジトリのコードは全て自宅で新規に作成したものであり、実務コードの持ち出しは一切含まれていません。

## 主な機能
* **業務用カレンダー生成**: 指定した年月、休日設定に基づく自動レイアウト。
* **祝日データ連携**: シートマスタを参照した祝日自動判定。
* **実行ログ出力機能**: 処理の開始・終了、およびエラー発生時の状況をテキストファイルへ出力。

## 設計のこだわり（保守・運用面）
実務での長期運用と、第三者への引き継ぎを強く意識して設計しています。

* **データとロジックの分離**: 設定値や祝日データをコード内にハードコーディングせず、定数化・マスタ化することでメンテナンス性を向上。
* **エラーハンドリングとログ**: 予期せぬエラー発生時に「どこで」「何が」起きたかを即座に特定できるよう、エラー番号と発生箇所をログに記録。
* **自己文書化を意識したコーディング**: 変数名・関数名を論理的に命名し、コメントを最小限に抑えても構造が理解できる可読性を追求。

## 開発環境
* OS: Windows 11
* Excel: Microsoft 365 (VBA)
